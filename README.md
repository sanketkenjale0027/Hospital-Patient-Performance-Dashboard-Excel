## 🏥 Hospital & Patient Performance Dashboard – Excel

## 📌 Project Overview

This project focuses on analyzing hospital and patient data using Microsoft Excel. An interactive Hospital & Patient Performance Dashboard was created to monitor patient admissions, readmissions, department-wise distribution, gender statistics, and hospital performance.

The dashboard transforms raw healthcare data into meaningful insights through charts, KPIs, and interactive filters.

## 🎯 Key Features

- Total Patients: Displays the total number of patients.
- ICU Patients: Tracks the number of patients admitted to the ICU.
- Died Patients: Shows the number of recorded patient deaths.
- Readmitted Patients: Analyzes patient readmission statistics.
- Average Days of Discharge: Displays the average patient discharge duration.
- Gender Analysis: Represents male and female patient distribution.
- Department-wise Analysis: Shows patient distribution across hospital divisions.
- Surgical Specialty Analysis: Compares patients across different surgical specialties.
- Length of Stay Analysis: Categorizes patients based on their hospital stay duration.
- Monthly Analysis: Tracks hospital performance and patient trends over time.
